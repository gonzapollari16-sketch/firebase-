# **App Name**: Crush Property

## Core Features:

- Property Display: Showcase property listings with images, descriptions, and key details.
- Filtering System: Allow users to filter properties based on criteria like price, location, and property type.
- Interactive Map: Incorporate a map feature to display property locations visually.
- User Login: Enable user authentication to save search preferences and favorite listings.
- AI Property Search: Natural language search using an AI tool to interpret user descriptions and find matching properties.
- Property Submission: Allow users to submit property listings with details, photos, and location information.
- Browsing History: Stores and retrieves the last search queries so that the users can find properties previously filtered or viewed, by city, zones or listing type

## Style Guidelines:

- Primary color: Deep purple (#4C4695), inspired by the gradients and modern feel of the design in the original HTML document.
- Background color: Dark slate gray (#1A1A2E), almost the same hue as the primary color but highly desaturated for a dark theme.
- Accent color: Vivid pink (#E63A8C), drawn from the CTA elements of the original HTML document. Contrast with the deep purple is important to draw attention to CTAs.
- Body and headline font: 'Inter' (sans-serif) for a modern, machined feel. A single font choice is adequate, as the app content is relatively simple.
- Use minimalist icons related to property types and features.
- Grid-based layout for property listings with clear separation of elements.
- Subtle transitions and animations when filtering properties.
